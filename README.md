## 🚀 Quick Start

### Installation

```bash
# Clone repository
git clone https://github.com/Scarlet-Twinz/ella-devcareer-track.git

# Navigate to directory
cd ella-devcareer-track

# Install dependencies
npm install

# Start development server
npm start

# Open in browser
open http://localhost:3000
```

### First-Time Setup

1. **Create Account**
   - Sign up with email
   - Verify email address
   - Complete profile

2. **Set Career Goals**
   - Define current role
   - Set 1-year, 3-year, 5-year goals
   - Identify target positions

3. **List Current Skills**
   - Add programming languages
   - Include frameworks and tools
   - Rate proficiency levels (1-5)

4. **Add Projects**
   - Link GitHub repositories
   - Add portfolio projects
   - Include project descriptions

5. **Track Learning**
   - Add courses you're taking
   - Log completed certifications
   - Track reading materials

## 📖 Usage Guide

### Adding Skills

1. Go to **Skills** tab
2. Click **Add New Skill**
3. Enter skill name (e.g., "React")
4. Select category (Frontend, Backend, DevOps, etc.)
5. Rate proficiency (1-5 scale)
6. Set mastery goal and timeline
7. Save

### Managing Projects

```
1. Navigate to Portfolio
2. Click "New Project"
3. Enter project details:
   - Project name
   - Description
   - Technologies used
   - GitHub link
   - Live demo URL
   - Start/end dates
4. Add metrics:
   - Lines of code
   - Team size
   - Downloads/users
5. Upload screenshots
6. Publish to portfolio
```

### Tracking Certifications
