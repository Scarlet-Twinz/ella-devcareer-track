#  DevCareer Track

A lightweight browser-based project and task tracker built with HTML, CSS, and JavaScript.

## Overview

DevCareer Track lets you add projects with a title, due date, and status, then view and manage them from a simple dashboard. Project data is persisted in the browser using `localStorage`.

## Features

- Add projects with a title and due date
- Track project status as In Progress or Completed
- Display total project count
- Display the number of projects currently in progress
- Delete projects
- Persist project data with browser `localStorage`
- Simple responsive frontend interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API

## How It Works

Projects are stored under the browser `localStorage` key `myProjects`. On page load, saved projects are rendered automatically. Adding or deleting a project updates the stored data and refreshes the project list.
